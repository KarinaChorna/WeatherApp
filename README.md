# Weather App

A simple weather application that retrieves current weather information for a city.

## Features

* Search weather by city
* Displays temperature, conditions, wind, sunrise, and sunset
* Caches weather data for offline use
* Uses IndexedDB for local data storage
* Progressive Web App (PWA) support

## Technologies

* HTML
* CSS
* JavaScript
* Weatherbit API
* IndexedDB
* Service Workers
